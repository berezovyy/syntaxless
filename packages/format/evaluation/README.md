# Format acceptance evidence

The gate records source code and the evaluation policy in the candidate's frozen
identity before reserved evaluation. Changes to either invalidate the freeze.
Historical freeze reports remain unchanged, and new candidates need a new freeze.

The evaluation writer imports no production parser/compiler or training renderer
at runtime. It authors expected intents directly and calculates formatter targets
using native Intl. Nine fixed witnesses also check manually specified currency,
percentage, negative-zero, missing-context, locale-conflict, leap-date and DST
results. Every positive intent has paired options and value/parts targets or an
expected compilation refusal.

The first consumed set matched 607/765 positives and refused all 640 negatives.
Four critical refusals exposed singular precision wording, an exact-count
qualifier and explicit native precision. Later supervision represents native
precision explicitly, including conflicts with stated counts. A development
comparison also exposed unsupported rounding words and fuller date/time context.

The second consumed set matched 536/767 positives and refused all 642 negatives.
All critical cases passed, but ordinary action preambles caused coverage misses.
Compositional action supervision fixed the failures without increasing the
8000-row corpus or hidden width 32. Fresh v3 matched all 767 positives and refused
all 642 negatives, and its model was promoted provisionally.

The completion audit found value-specific split fingerprints and an unbuffered
feature writer. The corrected v6 recipe groups literal substitutions and
base/negative pairs before splitting, and buffers feature output. All consumed
v1, v2 and v3 rows then passed as regression evidence. Fresh v4 matched 767/767
positives across ten families, with zero wrong accepted meanings and zero false
accepts among 642 negatives. Every fresh and previous critical control passed.

The same implementation assistant authored the bounded constructions and
numeric variations. The checks are not independent human evidence or a population
accuracy estimate. Reports preserve authorship, source/artifact identity, family
counts, separate wrong-meaning denominators and Wilson uncertainty intervals.
Native Intl targets share the runtime's locale data, so fixed witnesses and
browser checks provide additional evidence without claiming identical output
across all engines or locale-data versions.
